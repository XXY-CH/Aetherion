## 命名状态

Aetherion 是代号，不是已清查的公开名称。

现有研究提示可能存在冲突：

- GitHub 上已有使用 Aetherion 做 agent orchestration 的项目。
- PyPI 上存在 `aetherion` 包。
- AETHERION AI 相关商标记录。
- 既有 `aetherion.io` 平台，其企业 AI workflow 定位相邻。

在完成清查前，不要围绕 Aetherion 做不可逆品牌、域名、包名或商标决策。

## 竞争框架

Aetherion 不应被描述为“另一个 computer-use agent”。正确框架是：受治理 harness kernel，把 memory、permission、capability、proactive behavior 和 execution loop 连接在一起。

## 清晰差异化

- Local Supervisor 是根权限边界。
- Event Ledger 是事实层。
- Tool Policy Proxy 是敏感读取、数据外发和副作用动作 choke point。
- Capability Capsule 是受治理能力单元。
- Dreaming 产生 reviewable patch。
- Proactive 是 event-driven opportunity lifecycle。
- 人类可读合同是治理 source of truth。

## 产品护城河

护城河不是单个模型、单个浏览器控制能力或单个 connector，而是可审计权限边界、可演化能力系统、source-backed memory 和跨 surface 的一致治理。
