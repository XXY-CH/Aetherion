# Code of Conduct

[中文版本](CODE_OF_CONDUCT.zh-CN.md)

## Our Pledge

Aetherion is a local-first agent runtime project. We want the project to be rigorous, calm, and useful for people who care about trustworthy software. Contributors, maintainers, and users are expected to treat each other with respect and to keep technical disagreement focused on evidence, tradeoffs, and project goals.

## Expected Behavior

- Be respectful and patient in issues, reviews, discussions, and commits.
- Assume good intent, while still naming risks and defects plainly.
- Keep feedback specific, actionable, and grounded in the code, contracts, tests, or docs.
- Respect privacy. Do not post private messages, personal information, secrets, credentials, tokens, raw user data, or sensitive traces.
- Help preserve Aetherion's core safety boundaries: Local Supervisor authority, Event Ledger truth, Tool Policy Proxy gating, scoped leases, and reviewable changes.

## Unacceptable Behavior

- Harassment, insults, threats, stalking, or sustained disruption.
- Sexualized language or imagery in project spaces.
- Discriminatory language or exclusion based on identity, background, ability, nationality, religion, age, or similar protected traits.
- Publishing private information without explicit consent.
- Pressuring contributors to disclose secrets, credentials, private traces, customer data, or personal context.
- Using project channels to bypass security reporting, policy review, or maintainer decisions.

## Scope

This code applies in all project spaces, including issues, pull requests, discussions, commits, documentation, release notes, and project-related chat. It also applies when someone represents the project in public.

## Enforcement

Maintainers may remove comments, close issues or pull requests, request edits, temporarily limit participation, or permanently ban participants whose behavior harms the project or its contributors.

Reports should be sent privately to the maintainers through the repository's configured private contact path. If the report involves a security issue, follow [SECURITY.md](SECURITY.md). Do not include sensitive personal information in a public issue.

Maintainers will review reports as promptly as practical, preserve confidentiality where possible, and explain enforcement outcomes to the affected parties when appropriate.
